# Quickstart: Libraries (manual check)

Settings: author "Jane".

1. Header › Libraries → My library (empty, explains how to add), RRQuilts starter (13 blocks,
   1 collection "Basic colors"). Search "star" → Ohio Star; preview shows author, Public domain.
2. Starter › Ohio Star › Copy to my library → My library has it, author Jane, "Based on Ohio Star by
   RRQuilts contributors".
3. New project A › Blocks › New block "Jane Star", color it with a new own color › card menu › Add
   to my library… → bookmark icon. Fabrics & Colors › tap two own colors › Save to my library
   "Jewel".
4. New project B › Blocks → a "My library" group lists Jane Star (drawn in its colors); the tray's
   colors list "Jewel". Set Jane Star in a quilt.
5. B › Jane Star › Edit (makes your copy) › change a seam → back in Blocks the copy shows the sync
   icon › Sync to my library → Libraries › My library › Jane Star is revision 2.
6. Back in project A (reopen) → Jane Star's card shows sync (A's copy is older) › Sync → "has a
   newer version" → Cancel/Keep both/Replace as offered.
7. Libraries › My library › Categories… add "Stars"; Jane Star › Category… Stars; Tags & styles…
   style "eight-point" → Category/Styles filters and search "eight-point" find it. Delete the category → item
   uncategorized.
8. Jewel › Edit colors… rename/reorder/remove a color; Export (.rrqplt); import it in another
   project's Fabrics & Colors → colors added as own.
9. Back up… (My library + packs) → file `RRQuilts library backup.rrqlib`. Browser devtools: clear
   site data (or another profile) › Libraries › Import the backup → Restore → everything back.
10. Share as pack… with license CC0 → hint says share-alike required by an item (if any); an item by
    someone else that is All rights reserved is listed as left out. Import the pack on another
    profile → under Packs, read-only (Copy to my library); import again → "already installed";
    a higher revision offers the update with its changelog. Remove pack → projects keep copies.
11. Edit a library color from the tray (right-click › Edit a copy…) → own copy; if it came from a
    My-library collection, Fabrics & Colors offers "Sync to my library".
