# Data Model: saving slice

## `.rrq` change

`project.id`: string id (same format as other ids), required, generated by `createProject()`.
"Save as copy" assigns a new id.

## IndexedDB `rrquilts` (version 1)

| Store | Key | Value |
|---|---|---|
| `drafts` | project id | `{ id, name, savedAt: number, dirty: boolean, doc: RrqDoc }` |
| `recent` | project id | `{ id, name, openedAt: number, handle?: FileSystemFileHandle }` (max 20, newest first) |

## Project session (Pinia `project` store, in memory)

| Field | Meaning |
|---|---|
| `doc` | current `RrqDoc` or null |
| `handle` | file handle for overwrite-in-place, or null |
| `fileName` | last saved/opened file name |
| `revision` / `savedRevision` | change counters; dirty = revision ≠ savedRevision |
| `draftOk` | last draft write succeeded |
| `readOnly` | another tab holds the edit lock |
| `status` | derived: `new` · `saved` · `unsaved` · `unsaved-no-draft` · `read-only` |

### Transitions

- `newProject()` → doc, no handle, `new`
- `open(file|handle)` → parse; ok → doc, handle?, `saved`; lock not available → `read-only`
- `change(fn)` (blocked when read-only) → revision++, schedule draft
- draft write ok/fail → `draftOk`
- `save()` → handle? write : download → savedRevision = revision, draft marked clean
- `saveAs()` → new picker/download (same id) ; `saveCopy()` → new id
- lock stolen → `read-only`; `continueHere()` → takeover → reload latest draft → editable
