# Quickstart: Printing (manual check)

1. New project; Start a quilt with Ohio Star blocks (9″) and a border.
2. Block editor › Ohio Star copy › Print: Templates + Rotary chart, Size "As in <quilt>" → Preview.
   Template A is a 3½″ square (3″ finished), B a quarter-square triangle; counts match the quilt.
   Print to PDF at 100% → the 1″ square and template A measure true.
3. Rotary chart: 3½″ squares, 4¼″ squares cut twice diagonally; strips across 40″.
4. Change seam allowance, rounding (1/16″), mirror, line styles → preview follows; settings persist.
5. Quilt editor › Print: Quilt picture, Yardage, Rotary chart → yardage per color, backing
   (two panels when wider than 40″), binding.
6. Fabric width "Fat quarters" → yardage in fat quarters; backing/binding still from 42″ fabric.
7. A cm project: paper A4/A0, 7.5 mm seams, 5 mm rounding, 10 cm steps.
8. A huge custom block size (e.g. 30″): oversized templates split across pages with shaded
   overlaps.
