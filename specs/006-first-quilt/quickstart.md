# Quickstart & Validation: First Quilt

Automated: `make test` (actions, scopes, coloring, starter blocks, undo, hit-testing, 900-block
performance of model operations).

Manual (`make dev`; desktop and a tablet if available):

1. **Wizard**: Home → Start a quilt → step through (5×5, 10", no sashing, one 2" border) → Create →
   editor opens in Design with the first starter block selected.
2. **Set blocks**: Apply to All, tap a space → Ohio Star everywhere. Pick Nine Patch, Apply to
   Alternate, tap a space → checkerboard. Rotate (All) on a Nine Patch, Flip (This), Erase (This).
3. **Color**: Colors tab → pick a color → Paint (This) one patch; Paint (All) the same patch in all
   identical blocks; Spray (This) a patch; Swap a color; paint a border side (This) and all borders
   (All); Eyedropper picks a color up.
4. **Add color**: tray `+` → picker / HSL / hex → Add; right-click (long-press) a swatch → Edit /
   Delete (warns if used).
5. **Layout**: Layout tab → 6 columns, 2" sashing, sash border → placed blocks stay; change to 3
   columns → warning with the count of blocks removed; Cancel keeps everything.
6. **Borders**: Borders tab → Add outside, Insert inside, Clone, move, Mitered style, sides with
   All / L+R T+B / Each locks.
7. **Undo**: Ctrl+Z repeatedly undoes each step (a slider/typing burst is one step); Ctrl+Shift+Z
   redoes; buttons in the mode bar match.
8. **Canvas**: wheel zoom at the cursor, right-drag or Pan tool to move, Fit button; on a tablet
   pinch and two-finger pan; hover shows the space size; finished/center size always shown.
9. **Sketchbook**: quilt cards with thumbnails; Duplicate as variation → "Quilt 1 (2)" opens;
   Notecard edit; Move earlier/later and drag; delete a quilt (undo restores); delete a block that
   is in use → refused with the quilt names.
10. **Save/reopen**: Ctrl+S, reload, reopen from Recent → everything as left.
11. **Performance**: wizard with 30×30 → set All and paint All feel immediate.
