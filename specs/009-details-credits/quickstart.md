# Quickstart: Details, credits, licenses (manual check)

Settings: set your author name (e.g. "Jane").

1. New project › Details tab (last): title, author "Jane", license CC BY-SA 4.0 (default), units,
   notes. The license picker shows five options, each with a second line spelling out its terms.
   Type a title ending in a space → the space stays until you leave the field.
2. Blocks tab › built-in Ohio Star › menu › Preview → larger picture, author, Public domain, notes,
   Details button. Its colors are public domain too.
3. Edit the Ohio Star (makes your copy) › Details (first tab): author Jane, license = project's,
   "Based on" lists the original. Revision label under the title; hover → `id@version`.
4. Change a seam in your copy → no new credit entry for yourself; undo/redo each field separately.
5. Set your block to All rights reserved. Start a quilt using it › quilt Details: license locked to
   All rights reserved (lock icon, "Required by …"). Switch the block back to CC BY-SA → quilt unlocks.
6. Project Details: change the license to CC BY-NC-SA → existing blocks/quilts keep their licenses;
   a new block gets CC BY-NC-SA.
7. Import a `.rrqbl` from another author with CC BY-NC-SA, edit it → you become author, they appear
   under "Based on", and the license is locked to CC BY-NC-SA (can't pick CC BY-SA or CC0).
8. Quilt using that block › Details › "Blocks by others" lists it with its author and license;
   the quilt's license is locked at least to CC BY-NC-SA.
9. A block file without a license imports with the project's license; one without credits but
   with `source` shows that source under "Based on".
10. Save, reopen → author, license, credits, notes intact. Version hashes unchanged by editing only
    details (revision doesn't bump on save for a details-only change).
11. Project Details: Units Inches → Centimeters converts every size (10 in → 25.4 cm); undo reverts.
    Settings › Units for new projects = cm → a new project starts in cm.
12. Print a block page (spec 010) → its credits show there.
